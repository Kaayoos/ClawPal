# Contributing

Please open an issue before a large change. Include the supported board model,
Windows version and a small reproduction when reporting a problem. Remove
Wi-Fi passwords, pairing tokens, account data and personal paths from logs.

Submit original work, or work you are entitled to contribute, under the same
terms as the files being changed: GPLv3 for ClawPal, including its platform
linking permissions, and the existing licenses for vendor files. Preserve
copyright notices and document changes to third-party code. Do not submit
assets unless their redistribution rights are known.

Keep owned UI text in languages/*.json and run the language generator and
tests. Follow docs/BUILDING.md for full builds. Do not commit generated
executables, firmware images, credentials, device backups or local profiles.
Use the real contributor's Git identity; do not add tool identities as authors
or co-authors. Release notes are curated and do not auto-generate author lists.

Forks may contribute through pull requests. Official releases are published
only from Kaayoos/clawpal. See TRADEMARKS.md before distributing a derivative.
