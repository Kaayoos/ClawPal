Notices for the Python/PyInstaller-based esptool helper and its dependency families.
SOURCES.json records the exact upstream license-text snapshots and their hashes.
Snapshot tags identify the license texts, not a lockfile for Espressif's binary.
Espressif's v4.11.0 binary workflow uses Python 3.11 and unpinned dependencies;
it does not publish an exact dependency lockfile. Upstream license notices are
retained here alongside the GPL esptool and legacy-stub source distributions.
PyInstaller's license includes its bootloader redistribution exception.
The companion invokes the upstream tool as a separate process.
