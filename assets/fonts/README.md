# BuddyOS clock typeface

The clock uses a 96 px, four-bit antialiased subset of Montserrat Medium, matching the family used elsewhere in BuddyOS. Only `0123456789:-` are included. No runtime scaling or font decompression is required.

`Montserrat-Medium.ttf` is copied unchanged from the local Waveshare demo's LVGL 8.4 distribution: `vendor/waveshare-4.3b/ESP32-S3-Touch-LCD-4.3B-BOX-Demo/ESP-IDF/08_lvgl_Porting/components/lvgl__lvgl/scripts/built_in_font/Montserrat-Medium.ttf`. Its internal version is 7.200 and SHA-256 is `421f26b23e2be6b98373d32acd3cb2897b154d4bf0a77d26534ce476e4cbed53`.

The source identifies its copyright as “Copyright 2011 The Montserrat Project Authors” and is licensed under SIL Open Font License 1.1. `OFL.txt` contains the license from the [official Montserrat repository](https://github.com/JulietaUla/Montserrat/blob/master/OFL.txt), with the copyright line taken from this font's own metadata.

Generated with the official [LVGL font converter](https://github.com/lvgl/lv_font_conv), pinned to npm version 1.5.3. Install it locally with `npm install --prefix .tools/lv-font-conv --cache .tools/npm-cache --ignore-scripts --no-audit --no-fund lv_font_conv@1.5.3`, then run `scripts/generate_clock_font.ps1`. The converter's standard LVGL output includes its version-8 compatibility fields. `buddy_clock_font.h` exports the font for the UI.

Studio's light numerals use `Montserrat-Light.ttf`, version 9.000, from the [official Montserrat repository](https://github.com/JulietaUla/Montserrat/blob/master/fonts/ttf/Montserrat-Light.ttf) (SHA-256 `853de0dd715d6681f7038cf6cd53c1695b614657cbc57c8f542fe08d5b84e006`), under the same copyright line and `OFL.txt`. `scripts/generate_numeral_fonts.py` converts digits and the punctuation of times, temperatures and percentages at 96, 48, 32 and 24 px with the same converter. Each light font copies the line height and baseline of its Medium twin and falls back to it for any other glyph, so swapping fonts never moves a layout. Run it with `--converter <path to lv_font_conv.js>`.

Spotify metadata uses 20 px and 32 px subsets of the same source font, generated by `scripts/generate_music_fonts.ps1` and exported by `buddy_music_font.h`. These include Basic Latin, Latin-1, Latin Extended-A (including Polish letters), common punctuation and the euro sign. They preserve accented track and artist names beyond the built-in LVGL font's ASCII range. Other writing systems and emoji are outside this font subset.
