# ClawPal crab artwork

Original sheets supplied by the project owner. Thirteen states: happy, idle, thinking, working, sleeping, carrying, typing, music, error, sunny, cloudy, rainy, and night.

Each PNG is 384 by 288 pixels: eight columns and six rows of 48 by 48 frames. Read left to right, top to bottom. Preserve palette, transparency, and integer nearest-neighbor rendering. Desktop and device use the same original sheets. The error state is reserved for problems; it is never a random ambient activity.

Run `python scripts/generate_mascot.py --check` to validate generated LVGL pixels against the originals; omit `--check` to regenerate. See `THIRD_PARTY_NOTICES.md` for ownership.
