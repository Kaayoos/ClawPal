ClawPal 0.6.0 is the first public release, created by [MinimalPulse](https://minimalpulse.com/).

Download **ClawPal-Setup.exe** for Windows x64. The supported display is the
**Waveshare ESP32-S3-Touch-LCD-4.3B (800 × 480)**. Other ESP32 displays are not
supported. This installer is unsigned.

- USB first-run setup with optional, enabled-by-default backup and device checks.
- Animated crab Home, PC Monitor, Spotify controls, Codex usage/activity, Timer,
  Clock, and Weather with hourly and daily forecasts.
- Draggable Home shortcuts, Wi-Fi settings sync, screen/night preferences,
  English/Polish, Celsius/Fahrenheit and separate display/PC languages.
- Wi-Fi firmware updates preserving settings; official update checks only from
  Kaayoos/clawpal, with user-initiated installation.
- Optional FPS collection using the included checksum-verified Intel PresentMon.
- MinimalPulse attribution and offline licenses in About on both surfaces.

Existing users: exit ClawPal through its tray menu and run the new installer to
upgrade the companion, then install the display update from Updates over Wi-Fi.

Original ClawPal code and crab artwork are GPLv3; firmware includes an ESP-IDF
linking permission. Third-party licenses, matching source archives and build
instructions accompany this release. Integration logos remain their owners'
marks. See the repository's NOTICE, TRADEMARKS.md and THIRD_PARTY_NOTICES.md.

Known limits: this is the first public release; broader Windows/hardware testing
and backup-restore acceptance remain. Future partition-layout migrations may
require USB. Weather's free hosted API has separate noncommercial-use terms.
