# ClawPal 0.12.0

- New experimental board: the **LCDWIKI 2.8-inch ESP32-S3 Display (ES3C28P)**
  with capacitive touch. Choose it in setup's model list. It hasn't run on real
  hardware yet, so keep the backup turned on when you install. If the picture
  is upside down or mirrored, or taps land in the wrong place, please report
  it. The touchless ES3N28P is a different board and isn't supported.
- Every screen on 320 × 240 displays (the ES3C28P and the M5Stack CoreS3) is
  redesigned to fit above the footer. Nothing overlaps or is cut off, and
  scrolling moves one whole view at a time.
  - Home shows only the clock: the date, large numerals and the week, centred.
    Swipe up for the shortcuts.
  - The Clock app is a single centred column with large numerals. On this size
    the crab no longer appears on Home or Clock in either look.
  - The Apps menu fits all eight apps on one screen.
  - Media fits on one screen, Timer puts Start and Reset beside the ring, and
    PC Monitor, Claude Code, Codex and Weather give each card its own view.
  - The footer keeps only hints that fit, and the running-timer shortcut shows
    its full time.
- Displays with other screen sizes look exactly as before.
