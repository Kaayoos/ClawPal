# ClawPal 0.9.0

- Firmware updates and Wi-Fi changes sent from the PC now wait until you tap
  **Allow** on the display. Nobody on your network can replace the firmware or
  move the display to another network without someone at the screen.
- Wi-Fi updates no longer install older firmware. Use USB to go back a version.
- Open Wi-Fi networks without a password now work, including from the
  display's own setup page.
- Fixed a long location name stopping every later settings change from
  reaching the display.
- Firmware updates no longer fail on a brief Wi-Fi stall.
- ClawPal changes Claude Code's settings only when you click
  **Connect / repair Claude Code**. The new **Disconnect Claude Code** button
  puts your original status line back. Existing connections keep working.
- Restoring a backup on another PC or Windows account asks you to set the
  display up again instead of stopping the companion from starting.
- Very long CPU or GPU names no longer stop PC stats from showing.
- Update the PC companion first. A display on 0.9.0 does not accept updates
  or Wi-Fi changes from older companions. Pairing and settings are kept.
