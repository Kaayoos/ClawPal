# ClawPal 0.10.1

- Fixed the weather showing "unavailable". The redesigned display apps used up
  the display's fast internal memory, leaving none for Wi-Fi and the secure
  connection to the forecast service. The interface now moves to the larger
  external memory once internal memory runs low.
- A display update no longer asks you to update the PC app first when the
  installed one already works with it.

Created by [MinimalPulse](https://minimalpulse.com/).
