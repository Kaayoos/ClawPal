# ClawPal 0.10.1

- Fixed the weather showing "unavailable". The redesigned display apps used up
  the display's fast internal memory, leaving none for Wi-Fi and the secure
  connection to the forecast service. The interface now moves to the larger
  external memory once internal memory runs low.
- A display update no longer asks you to update the PC app first when the
  installed one already works with it.
- Redesigned approval prompts on the display. A firmware update shows the
  installed and new version and which PC asked; a Wi-Fi change shows the new
  network. A bar counts down the time left to answer.
- The Claude Code and Codex alert now leads with the waiting task, shows its
  project and how long ago it asked, and uses the app's own colour.
- While an update installs, the crab carries it along a progress bar, then
  shows the signature check and the restart. If an update fails, the display
  says so and keeps the current version.
