# ClawPal 0.9.1

- Added opt-in Live Claude limits in Companion settings. Reads the signed-in
  Desktop or native CLI account's current usage and reset times from Anthropic.
- Fresh limits refresh every minute during active sessions. Failed requests keep
  an honestly aged cached reading; rate-limit responses respect retry delays.
- Account changes discard the previous live reading. Credentials remain on the
  PC except for the authenticated request to Anthropic and never enter logs or
  device telemetry. No chat messages are sent.
- Fixed stale Desktop usage history overwriting newer status-line limits.
- Replaced the Claude integration logo on the display and in the companion.
- Preserved 0.9.0's settings, pairing, and on-device approval for remote changes.

**After updating:** enable **Companion > Live Claude limits** and save to use
current account readings. The switch remains off until you choose it.
