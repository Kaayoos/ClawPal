# ClawPal 0.8.0

- Experimental firmware and installer profiles for Waveshare 5-inch, 7-inch
  (8/16 MB), 2.8C, Guition ESP32-4848S040C_I and M5Stack CoreS3 displays.
- Shared square and compact layouts with scrollable apps and fixed navigation.
- Model-specific USB backup/install/restore, Home previews, and Wi-Fi updates.
- All new hardware profiles are untested on physical devices and may not work.
  The original Waveshare 4.3B remains the hardware-tested target.
- Upgrade the PC companion first. Existing pairing, preferences and display
  settings are retained. Keep the exact board model selected when using USB.

Created by [MinimalPulse](https://minimalpulse.com/).
