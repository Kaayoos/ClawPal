# ClawPal 0.10.0

- Redesigned display apps. Music shows an album-tinted cover with the dancing
  crab, a draggable seek bar, shuffle, repeat, and Spotify volume and mute.
  Codex and Claude Code share one page with usage gauges, reset countdowns, a
  pace forecast and task cards. PC Monitor, Timer and Weather use the same card
  style, with dedicated layouts for 480 × 480 and 320 × 240 screens.
- The time zone now follows the location you choose, for about 590 places
  worldwide. A few regions whose rules the display can't follow exactly keep
  the manual list.
- Safer local network: every request from the PC to the display is signed, so
  the pairing token no longer crosses the network and recorded requests can't be
  replayed. Traffic is still unencrypted; keep the display on a trusted network.
- Wi-Fi firmware updates must now be signed by the ClawPal release key.
  Installing over USB, including your own builds, works as before.
- Music works with any player in Windows' media controls, including Apple
  Music, TIDAL and browsers, and shows the album cover on the display.
- When Claude Code or Codex waits for your answer, the display shows a
  full-screen alert on any app. **Show on PC** brings that window forward.
- Locking or sleeping the PC makes the crab nap instead of showing "PC offline".
- CPU temperature appears when LibreHardwareMonitor, or HWiNFO with shared
  memory, is running. ClawPal still installs no driver.
- ClawPal now appears in Windows' installed apps and can be uninstalled from
  there, or with `--uninstall`. It also disconnects Claude Code.
- A damaged settings file no longer stops the companion from starting. It is
  set aside and setup starts again.
- The display reports its reset reason, uptime and memory low-water marks, and
  keeps a crash report after a USB install writes the new partition table.
- Fixed "Limits unavailable" after Claude Desktop moved its data to the new
  Claude-Data folder.
- Preserved settings, pairing, and on-device approval for remote changes.

**Update the PC app first.** This display firmware only talks to companion
0.10.0 or newer, so ClawPal offers the PC update before the display update.
