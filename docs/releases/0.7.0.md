# ClawPal 0.7.0

Claude Code joins Codex as a separate display app, with its supplied Anthropic
logo, five-hour and weekly remaining usage, reset times, recorded session
activity and keyboard crab. Enable it in Apps and pin it from Home settings.
Existing shortcut order and automatic-opening preferences are preserved.

The Windows bridge uses Claude’s supported status-line and session hooks without
reading login tokens or retaining prompts. Restart existing Claude Code sessions after
connecting it. Usage appears after the first response when the subscription
reports it. Local Desktop Code sessions also read the matching account’s saved
plan-usage history. These percentages show their age, expire after 30 minutes,
and do not invent reset times. WSL and remote sessions are not supported.
The Desktop reader fix only requires replacing the PC companion; a display
already running 0.7.0 needs no firmware update.

Update the PC companion first, then install display firmware over Wi-Fi.
Firmware and companion must both be 0.7.0 for this app. Settings are retained.
